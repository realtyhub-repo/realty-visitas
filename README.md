# Realty Visitas

Realty Visitas es el microservicio encargado de administrar la información relacionada con las visitas a los inmuebles de RealtyHub. Su función es organizar los registros de las visitas y apoyar la gestión de estas actividades dentro de la plataforma.

## Funcionalidades

- Agendamiento de visitas a propiedades, evitando cruces de horario del agente y del inmueble.
- Cancelación y registro de visitas realizadas.
- Publica eventos cuando una visita se agenda, se cancela o se realiza.

## Tecnologías

Java 21, Spring Boot, PostgreSQL, Flyway y RabbitMQ.

## Puerto

El servicio se ejecuta en el puerto `8085`.
